## Role card

Put these four lines at the top of every role's own instruction file (the lead's brief, the
agent's spec). Keep the labels exactly as they are. One role, one card, one home.

- **Delivers**: what this role hands over and how you can tell it is good enough. Write the result, not the steps. It must be checkable. This line is never just a pointer.
- **Owns**: the boundary. If the file already has a scope section, write "see <section>".
- **Standard**: how good is good enough. Point to where it is already written; write it here only if it is written nowhere else.
- **Enforced by**: rule IDs from the registry (gate or scheduled). If nothing enforces it, write "discipline only". Never claim a gate that does not exist.
