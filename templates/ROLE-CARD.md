## Role card

Put these four lines at the top of every role's own instruction file (the lead's brief, the
agent's spec). Keep the labels exactly as they are, and keep each role's card in one file only.

- **Delivers**: what this role hands over, stated as a result someone can check, not as steps. Never just a pointer.
- **Owns**: the boundary. If the file already has a scope section, write "see <section>".
- **Standard**: how good is good enough. Point to where it is already written; write it here only if it is written nowhere else.
- **Enforced by**: rule IDs from the registry (gate or scheduled). If nothing enforces it, write "discipline only". Never claim a gate that doesn't exist.
